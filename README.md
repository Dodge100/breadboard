# breadboard

an all-in-one utility app for macos. instead of having 12 different apps in the background, i tried to focus on adding tons of customizability into one app while tying into existing mac features.

breadboard allows you to better customize stuff that i always thought you should be able to but aren't allowed to. for example, you can create custom menu bar items with unique submenus and subitems for right and left click. or, if you're more of a power user, the app supports creating vim style bindings with out-of-the-box support for chording and variables.
